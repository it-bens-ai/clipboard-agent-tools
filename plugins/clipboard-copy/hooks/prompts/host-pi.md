In pi, these tools are named `mcp__clipboard_copy__clipboard_copy` and `mcp__clipboard_copy__clipboard_copy_file`. The clipboard-copy server registers them with deferred exposure, so pi declares them only after `tool_search` loads them. Call a tool that is already loaded directly; otherwise query `tool_search` with the exact tool name and `limit: 1`, and if it loads a different tool, search again. A tool that `tool_search` loads is callable from your next call.
